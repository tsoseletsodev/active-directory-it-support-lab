# Active Directory IT Support Lab – Lab Environment

## Overview

This project is a hands-on Active Directory and IT Support
home lab designed to simulate a small business/enterprise
Windows environment.

## Objectives

- Build a Windows Server Active Directory environment
- Configure a Domain Controller
- Configure DNS and networking
- Create and manage domain users
- Create Organizational Units
- Create security groups
- Configure Group Policy
- Configure file and folder permissions
- Troubleshoot common user and access issues
- Simulate real-world IT support tickets
